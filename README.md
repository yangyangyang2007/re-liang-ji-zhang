# 热量记账

一个手机网页版健康记录应用：记饮食热量、记每天花费、记体重、记跑步、健身计划打卡。

## 功能

- 今日总览：今天吃了多少大卡 / 蛋白（目标 2100 大卡、130 克蛋白）、今天花了多少钱（目标默认 50 元/天，可改）、本月累计花费
- 记饮食：拍照识别食物热量和蛋白（AI 识别，结果可改再保存）；或手动记一餐，常用食物点一下自动填
- 记花费：手动记一笔，分类、备注、日期；不接银行、不读账单
- 历史：每天的汇总，点一天展开看明细、可删单项；近 7 天日均热量和日均花费
- 体重：记晨起空腹体重，只看周均值和趋势线
- 跑步：记跑步，满 2 公里计数，目标一学期 30 次
- 健身：三分化训练计划（胸+三头 / 背+二头 / 肩+腹，练三休一），一键生成或自己组动作；动作库带演示动图、要点和教学视频链接；练完打卡

## 技术

- 前端：React + TypeScript（`client/`）
- 后端：TypeScript server actions + Drizzle ORM + SQLite（`server/`、`drizzle/`）
- 拍照识别走服务端推理（本项目原来跑在 Muse Spaces 运行时上，`server/src/privileged.ts` 用的是运行时的推理与文件能力；自己部署时把 `analyzePhoto` 换成你自己的视觉模型接口即可，接口配置参考小程序版 `config.js` 的写法）

## 运行

```bash
bun install
bun run dev
```

## 备注

- 数据存在本地 SQLite，删库数据就没了；本仓库不含任何真实记录数据。
- 动作演示动图来自公开动作库（JEFIT、BurnFit 等），仅作演示；教学视频链接指向 B 站等公开页面。
